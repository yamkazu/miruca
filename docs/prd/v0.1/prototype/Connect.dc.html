GitHub をつなぐ

まだ GitHub の組織がつながっていません。miruca の GitHub App を組織に入れると、その組織のリポジトリの PR の動きが見られるようになります。

App を入れてつなぐ

GitHub の画面で、App を入れる組織と、対象のリポジトリを選びます。

GitHub をつなぐ

すでに App が入っている組織をつなぐ

同じ会社のほかの人が App を入れていれば、GitHub のアカウントで確かめるだけでつなげます。

インストール済みの組織をつなぐ

miruca が GitHub で読むもの

  • PR の情報（タイトル、作成者、作った時刻とマージした時刻、変更した行数）と、リポジトリの名前だけを読みます。
  • コードは読みません。GitHub に書き込むこともしません。
  • App を入れられるのは、GitHub の組織のオーナーです。リポジトリの管理者は、自分が管理するリポジトリだけに入れられます。それ以外の人が進めると、オーナーへの依頼になります。
