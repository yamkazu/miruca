# miruca 0.1 のプロトタイプ

[PRD: miruca 0.1](../README.md) の画面を、クリックで行き来できるようにした使い捨てのプロトタイプです。データはサンプルで、どのボタンも次の画面へ進むだけです。

## 見る方法

claude.ai のキャンバスで開きます: https://claude.ai/artifact/8umNrWZ3SSFDxGKyo3Qvvz

キャンバスは作った人だけが開けます。ほかの人に見せるときは、キャンバスの Share から共有します。

このフォルダのファイルは、キャンバスの中身をそのまま写したものです。`.dc.html` は Claude Design のキャンバスの形式で、キャンバスの実行環境（`support.js`）がないとブラウザでは表示できません。画面の構成と文言を読むための控えとして置いています。

## 画面

| ファイル | 画面 |
| --- | --- |
| `Main.dc.html` | 1. ログイン |
| `Sent.dc.html` | 2. メールを送りました |
| `Verify.dc.html` | 3. メールのリンクを開いた画面 |
| `Connect.dc.html` | 4. GitHub をつなぐ前 |
| `Repos.dc.html` | 5. リポジトリの一覧 |
| `Insights.dc.html` | 6. インサイト（期間の切り替えが動く） |
| `InsightsEmpty.dc.html` | 7. インサイト（PR の動きがないとき） |
| `canvas.json` | キャンバス上の並び |

## 扱い

- 動きや仕様が PRD と食い違ったら、PRD を正とします。
- 実装が始まったら、このプロトタイプは更新しません。0.1 の画面を決めたときの記録として残します。
